🧭 Overview
BUITEMS Calculator Hub is a single self-contained HTML file that turns everyday academic calculations into a clean, modern, university-branded experience — no installs, no backend, no dependencies to manage. Open it in a browser and it just works.
---
🎨 UI / Design
The interface is built to feel like a real university portal — calm, professional, and easy on the eyes — not a generic calculator page.
Design Language
Element	Detail
🎨 Color Palette	Soft university blues (`#0B3F6E`) with a restrained gold accent (`#B8892A`) — no neon, no harsh gradients
🌗 Light / Dark Mode	One-tap toggle in the header, with a purpose-built dark palette (not just an inverted light mode)
🔠 Typography	Fraunces for headings (editorial, official feel), Inter for body text, JetBrains Mono for numeric results
🧭 Navigation	Fixed top header with an underline-style tab menu — collapses into a mobile dropdown on small screens
📌 Layout	The page itself never scrolls — header and footer stay pinned, only the content pane scrolls, like a real dashboard app
🪪 Branding	Official BUITEMS crest embedded throughout — sidebar, hero, assignment page, generated front page, and chatbot header
🧩 Cards & Shadows	Rounded 12–16px corners, soft layered shadows, consistent spacing across every panel
✨ Micro-interactions	Hover lifts on dashboard cards, a live pulsing "online" indicator on the chat widget, an animated rotating quote on the homepage
What Makes It Feel Premium
A hero section with the full BUITEMS name, crest, and a rotating "live quote" ticker.
A certificate-style front-page generator — gold-and-blue frame, dashed inner border, and the real university crest — not just plain text output.
Every result card is rendered like an official summary slip, with Copy / Print / Download PDF built in.
Consistent icon language across every calculator page, tuned to stay visible and legible in both light and dark themes.

✨ Features
🧮 GPA Calculator — add subjects with grade and credit hours, get instant semester GPA
📚 CGPA Calculator — add multiple semesters, get total credit hours, average GPA, overall CGPA, letter grade, and academic standing
🎯 Admission Merit Calculator — Matric / Intermediate / Entry Test with automatic percentages and weighted contributions (10% / 40% / 50%)
📊 Percentage Calculator and 📅 Age Calculator — fast standalone tools
📄 Assignment Front Page Generator — save your details once, generate an official cover page with the BUITEMS crest, print it, or download it as a PDF
🤖 AI Assistant — a floating live-chat widget with suggested questions and free-text answers about how each calculator works
✅ Smart input validation — numbers only, single decimal point, max 5 decimal places, auto-rounded results with trailing zeros trimmed
🌗 Light / dark theme toggle that remembers your preference
📱 Fully responsive — desktop, tablet, and mobile
📦 Zero dependencies to install — everything, including images, is bundled into one HTML file
---
🛠 Tech Stack
HTML5, CSS3, vanilla JavaScript — no framework, no bundler, no build step
Font Awesome for standard iconography
Inline SVGs for brand icons (LinkedIn, GitHub, WhatsApp) — guaranteed to render even if external fonts fail to load
jsPDF (via CDN) for in-browser PDF generation
Google Fonts — Fraunces, Inter, JetBrains Mono

🚀 Deployment
GitHub doesn't render HTML files directly — opening `index.html` on github.com only shows source code. To see the site live, use GitHub Pages:
Make sure the app file is named `index.html` at the root of the repo.
Go to Settings → Pages in your repository.
Under Build and deployment, set Source to Deploy from a branch, choose the `main` branch and the `/ (root)` folder, then Save.
Wait a minute, then visit `https://kumailahmedkakarr.github.io/calculator/`.
Run locally
No server or build tools required — just download `index.html` and open it in any modern browser.
